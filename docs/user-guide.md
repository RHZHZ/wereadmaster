# WxReadMaster 用户指南

> **status: current** · 2026-08-06
> **适用版本**：`v1.0.18`
> **术语依据**：[GLOSSARY.md](./GLOSSARY.md)

这份指南按“我要完成什么”组织。建议第一次使用时从第 1 节开始；遇到具体问题时直接跳到对应章节。

## 0. 先看平台能力

不同运行环境的能力范围不同。先确认当前使用的是 Windows 桌面端、Android，还是 Web Preview。

| 能力 | Windows 桌面端 | Android | Web Preview |
| --- | --- | --- | --- |
| 查看已同步内容 | 支持 | 支持 | 查看已准备数据 |
| 微信读书同步 | 支持 | 支持 | 不支持 |
| 微信书架、候选书架 | 支持 | 支持 | 只读查看 |
| 本地书库与阅读器 | 完整能力 | 移动阅读优先 | 不支持本地命令 |
| 本地划线、想法和阅读记录 | 支持 | 按移动端能力 | 只读查看 |
| 主动生成书籍复盘、阅读指南等成果 | 支持 | 以应用实际能力和配置为准 | 不支持 |
| 文档导出 | 支持 | 按移动端能力 | 不支持桌面导出 |
| SQLite 备份与恢复 | 支持 | 按移动端能力 | 不支持 |
| 应用更新 | 应用内更新或下载安装包 | 下载 APK 后按系统安装 | 不适用 |

Web Preview 是只读入口：可以查看已准备的阅读数据和成果，但不能写入阅读状态、执行桌面导出、调用 AI 或执行本地阅读器命令。

## 1. 15 分钟快速上手

### 第一步：安装并打开

从 [GitHub Releases](https://github.com/RHZHZ/wereadmaster/releases) 获取对应平台版本：

- Windows 下载 x64 安装包。
- Android 下载签名 APK，并按系统提示完成安装。

### 第二步：保存微信读书凭据

1. 打开 `设置 > 账户与同步`。
2. 按微信读书官方页面获取 API Key。
3. 保存 Key，并确认页面显示凭据状态正常。
4. 不要把 Key 粘贴到笔记、诊断信息、截图或导出文档中。

### 第三步：同步第一批数据

1. 进入 `书架`，点击 `同步书架`。
2. 如需笔记，进入 `笔记` 后执行对应同步。
3. 如需趋势数据，进入 `统计` 后同步当前统计。
4. 等待同步结果提示完成，再开始生成成果。

同步结果会进入本地缓存。之后可以在没有远端数据变化时继续查看已经同步的内容。

### 第四步：配置 AI（可选）

如果要生成书籍复盘、阅读指南、阅读路线、周期复盘、选书决策或使用 AI 阅读助手：

1. 打开 `设置 > AI 设置`。
2. 选择 Provider 预设，或配置自定义 Provider。
3. 填写模型和 API Key。
4. 先测试连通性，再测试结构化输出兼容性。
5. 如果模型列表刷新失败，可以按照服务商文档手动填写模型名称。

AI 只在你主动触发具体动作时处理对应的阅读上下文，不会在后台自动生成。

### 第五步：配置语义索引（可选）

语义索引用于让笔记搜索理解相近表达，而不仅是匹配相同字词。它独立于聊天 AI：可以使用同一个服务商，但 Embedding 模型、接口和 Key 授权按独立配置处理。

1. 打开 `设置 > AI 设置 > 语义索引`。
2. 填写 OpenAI-compatible 的 Embedding Base URL、模型和独立 API Key。
3. 勾选“允许发送笔记正文生成向量”，并在确认弹窗中明确授权。
4. 保存设置，点击“测试 Embedding 连接”。测试成功会显示模型向量维度。
5. 点击“开始构建”，等待状态显示“已就绪”。任务中断可点击“继续构建”，不需要从头开始。

构建时会把本机笔记正文分批发送给所配置的 Embedding Provider；生成的向量只保存在本机，默认不进入备份。普通查询时仅发送查询文本，笔记正文仍在本机读取。

### 第六步：完成一次最小闭环

推荐先选择一本已经有划线或想法的书：

1. 在 `书架` 或 `笔记` 中打开书籍详情。
2. 查看笔记数量和材料内容。
3. 点击 `本书阅读指南`，确认下一步读法。
4. 再进入 `书籍复盘`，生成一次结构化成果。
5. 在成果页查看结果，并尝试导出一份 Markdown。

## 2. 三类数据和保存位置

应用中有三类容易混淆的数据来源。

| 数据类型 | 来源 | 典型内容 | 默认保存方式 |
| --- | --- | --- | --- |
| 微信读书数据 | 你的微信读书账号 | 书架、笔记、统计、发现结果 | 同步到本地数据库或缓存 |
| 本地图书数据 | 你导入的文件 | EPUB、TXT、Markdown、阅读进度、划线和想法 | 本地书库与浏览器/WebView 存储 |
| AI 阅读成果 | 你主动生成或记录 | 书籍复盘、阅读指南、阅读路线、周期复盘、选书决策、助手对话 | 本地 AI 资产缓存和导出目录 |

本地图书与微信书架是两个来源版本：

- 可以在书库中关联，用于识别“可能是同一本书”；
- 不会自动合并阅读进度、划线、想法或 AI 缓存；
- 对本地图书的阅读记录不会写回微信读书。

## 3. 同步微信读书数据

### 3.1 配置微信读书 API Key

进入：

```text
设置 > 账户与同步
```

页面只显示凭据状态，不显示已保存的 Key 正文。删除凭据不会自动删除已经同步到本机的书架、笔记和统计缓存。

### 3.2 同步书架

1. 进入 `书架`。
2. 打开 `微信书架`。
3. 点击 `同步书架`。
4. 等待结果提示完成。
5. 使用类型、分类、书单和关键词筛选内容。

微信书架支持：

- `全部`、`电子书`、`有声书`、`文章收藏`等范围筛选；
- 按书名、作者和分类搜索；
- 从书卡进入详情；
- 复制书名；
- 跳转发现页搜索；
- 保存为候选。

### 3.3 同步笔记和统计

- 需要整理划线和想法时，进入 `笔记` 同步对应数据。
- 需要查看阅读趋势时，进入 `统计` 同步当前周期数据。
- 如果远端同步失败，先查看设置页的凭据状态和错误提示，再考虑代理或接口版本问题。

同步不会自动生成书籍复盘、阅读指南或其他 AI 成果。成果生成必须由你主动触发。

### 3.4 Android 网络代理

Android 上如果微信读书同步失败，可以在以下入口配置代理：

```text
我的 > 微信读书代理设置
```

或：

```text
设置 > 账户与同步 > 微信读书网络代理
```

支持代理工具实际提供的 HTTP 或 SOCKS 地址，例如：

```text
http://127.0.0.1:7890
socks5://127.0.0.1:1080
```

该代理只影响微信读书同步接口，不影响 AI Provider 或应用更新。

## 4. 书架、候选书架和本地书库

### 4.1 微信书架

适合管理已经同步的微信读书内容：

1. 进入 `书架 > 微信书架`。
2. 用筛选器缩小范围。
3. 搜索目标书。
4. 打开详情查看阅读状态、笔记和可用成果入口。
5. 根据需要标记阅读状态或整理状态。

### 4.2 候选书架

候选书架只保存本机的候选关系，不写回微信读书。

推荐流程：

1. 在 `发现` 中搜索书名、作者或主题词。
2. 查看推荐、相似书或搜索结果。
3. 将合适的书保存到候选书架。
4. 进入 `候选书架`，确认、移除或搜索书源。
5. 需要做下一本取舍时，点击 `生成选书决策`。

候选状态、阅读生命周期和整理状态是三个独立维度。一本书可以同时是候选、阅读中和待整理。

### 4.3 本地书库

本地书库用于导入自己拥有的 EPUB、TXT 和 Markdown 文件。

1. 进入 `书架 > 本地书库`。
2. 选择文件或粘贴路径。
3. 导入后可使用网格或列表视图浏览。
4. 打开书籍进入本地阅读器。
5. 如需识别同一本书，可关联微信读书版本，但不要把关联理解为自动合并。

## 5. 本地阅读器

### 5.1 阅读和调整

从本地书库打开书后，可以使用：

- 目录跳转；
- 字号调整；
- 行距调整；
- 阅读主题；
- 正文搜索；
- 工具侧栏。

Markdown 图书支持标题、引用、列表、分隔线和代码块等基础渲染。

### 5.2 选区记录

选中文本后可以执行：

- 划线；
- 写想法；
- 向 AI 提问。

右侧侧栏可以查看已有划线、想法和 AI 提问记录。导出按钮可以将本地阅读记录输出为 Markdown。

这些记录默认独立保存在本地，不会影响微信读书原始数据。

### 5.3 本地阅读器的环境边界

本地阅读器涉及浏览器或 WebView 存储。Web Preview 只能查看已经准备好的内容，不能执行新的本地写入或本地命令。

如果某个环境不支持本地阅读器 AI 请求，应用应以界面提示为准；需要生成时回到具备对应本地能力并已配置 AI Provider 的应用环境。

## 6. 笔记与阅读状态

### 6.1 笔记页

进入 `笔记` 后可以：

1. 按书查看划线、想法和书签信息。
2. 在卡片视图和章节视图之间切换。
3. 查看材料数量和内容密度。
4. 进入书籍详情或生成书籍复盘。
5. 使用单项或批量导出。

微信读书接口通常只提供书签数量，不提供书签正文。因此导出内容通常包含划线和想法，不包含书签正文。

### 6.2 三维阅读状态

v1.0.17 将阅读状态拆成三个互不覆盖的维度：

| 维度 | 回答的问题 | 示例 |
| --- | --- | --- |
| 候选关系 | 是否保留为候选，以及候选来源 | AI 推荐、用户保存、已确认书源 |
| 阅读生命周期 | 现在处于什么阅读阶段 | 想读、在读、暂停、读完、暂缓 |
| 整理进度 | 笔记或成果是否完成整理 | 无、待整理、已整理 |

因此：

- 标记“已读完”不等于“已整理”；
- 标记“已整理”不会移除候选关系；
- 加入候选不会覆盖当前阅读进度；
- 修改一个维度不会清除另外两个维度。

### 6.3 推荐的状态使用方式

- 还没决定是否阅读：保留候选关系，生命周期设为想读。
- 正在阅读：生命周期设为在读；有内容需要处理时，再标记待整理。
- 已读完但还没整理：生命周期设为读完，整理进度仍为待整理。
- 成果已经确认并保存：整理进度改为已整理。
- 暂时不再继续：使用暂缓，不要把暂缓当作物理删除。

## 7. 成果：复盘、指南、路线和报告

### 7.1 书籍复盘

书籍复盘把单本书的本地笔记整理成结构化成果，通常包含：

- 主题概览；
- 关键观点；
- 行动项；
- 代表性摘录；
- 复盘问题。

推荐在笔记足够多、读完一个阶段或读完整本书后生成。生成前应确认当前书的笔记已经同步或读取完成。

### 7.2 快照式全量笔记归纳

普通书籍复盘和助手问答受上下文预算限制，不等同于对一本书全部笔记的归纳。需要完整处理某本书的本地笔记时，使用书籍复盘页的“快照式全量笔记归纳”。

1. 打开一本书的 `书籍复盘` 页面。
2. 查看本地笔记数量和预计批次数。
3. 勾选授权确认，明确同意将该次任务快照中的原始笔记正文发送给当前 AI Provider。
4. 点击“创建全量归纳任务”，再点击“继续调用 Provider”开始处理。
5. 页面会显示已处理数量、批次进度和当前模型；中断后可继续，失败批次可单独重试，也可取消任务。

任务使用创建时的笔记快照。之后新增或修改的笔记不会悄悄混入当前任务；需要包含新笔记时，请创建新的快照任务。

### 7.3 阅读指南

阅读指南回答：

> 这本书接下来怎么读、怎么整理、什么时候适合复盘？

从书籍详情点击 `本书阅读指南`。它不是简单摘要，而是围绕当前书的推进建议和下一步行动。

### 7.4 阅读路线

如果要围绕主题安排多本书：

1. 先在发现页找到相关书籍。
2. 保存到候选书架。
3. 在阅读指南中选择候选书。
4. 生成阅读路线。
5. 回到 `成果 > 阅读指南` 查看和继续使用。

### 7.5 阅读报告

进入 `统计` 或 `成果 > 阅读报告`：

1. 选择总计、年度、月度或周度。
2. 查看阅读时长、书籍数量和主题趋势。
3. 按需要生成周期复盘或报告图片。
4. 在移动端可将报告图片保存到系统相册或通过系统分享。

## 8. 导出成果

### 8.1 单项导出

单本笔记、书籍复盘、周期复盘、阅读指南、阅读路线和选书决策使用统一导出流程：

1. 在当前成果页点击对应的 `导出…` 按钮。
2. 独立选择 Markdown、Obsidian、Notion 中至少一个已配置目标。
3. 核对导出目录、Vault 或 Notion 数据库摘要。
4. 开始导出。
5. 在结果页按目标查看成功、失败、跳过、警告、文件路径或 URL。
6. 如果只有部分目标失败，使用 `重试失败项`，不要重复提交已经成功的目标。

导出弹窗中的目的地摘要是只读的。长期配置请前往 `设置 > 导出设置` 修改。

### 8.2 批量导出笔记

1. 进入 `笔记 > 批量导出`。
2. 等待本地缓存预检完成。
3. 选择导出策略和并发数。
4. 按需要只导出选中的书，或排除没有划线和想法的书。
5. 核对预检结果后开始导出。

批量导出只处理本地已有缓存，不会因为打开向导或执行导出而自动同步微信读书，也不会自动生成书籍复盘。

### 8.3 批量导出书籍复盘

1. 进入 `成果 > 书籍复盘`。
2. 点击 `导出书籍复盘`。
3. 搜索、筛选并选择已经生成书籍复盘的书。
4. 在设置页选择一个或多个导出目标。
5. 点击 `开始导出`，进入独立执行页。
6. 等待执行完成，在结果页查看每个“书籍 × 目标”的结果。
7. 失败时点击 `重试失败项`，只重试精确失败的目标。

执行期间不能通过关闭按钮、背景点击或 Escape 取消底层任务。不要把关闭受控理解为应用卡死。

### 8.4 Notion 导出边界

Notion 当前是单向导出：

- 可以连接已经共享给 Integration 的数据库；
- 可以创建标准阅读成果库；
- 可以写入阅读成果、标签和封面；
- 标签被 Notion 拒绝时，对应目标会明确失败；
- 可以在结果页重试失败目标；
- 不会把 Notion 内容同步回本地；
- 不会后台改造用户已有数据库的视图和结构。

## 9. AI 阅读助手

AI 阅读助手从右下角或相关页面打开。可以选择上下文范围：

- 全局；
- 当前书；
- 笔记；
- 统计；
- 候选书；
- AI 阅读成果；
- 本地选区。

可以控制：

- 是否使用个性化上下文；
- 是否使用阅读记忆；
- 是否发送原始笔记；
- 是否保存对话历史。

建议在提问前先确认上下文范围。如果不希望模型看到原始笔记，保持原始笔记开关关闭。

助手支持历史线程、继续追问、删除线程和清空本地对话记录。AI 推荐的新书可以加入候选书架，必要时再通过发现页确认书源。

### 9.1 搜索当前书的笔记

在当前书、笔记范围内，直接提问即可搜索本地笔记，例如：

- `找出与宽恕有关的笔记`
- `我关于专注力有哪些想法？`
- `只看我的想法`
- `包含“宽恕”的所有笔记`

结果会显示“混合检索”“词法检索”或“本地词法回退”。普通查询在索引就绪时会融合本地词法和语义召回；包含精确短语、要求全部匹配、分页续查时会优先使用本地词法检索，以保证结果可验证、可稳定翻页。

当 Embedding Provider、索引或配置暂不可用，应用会标注“本地词法回退”并继续返回本地结果，不会因此中断搜索。原始笔记正文是否显示仍由阅读助手的独立授权控制。

## 10. 设置与 Notion

### 10.1 账户与同步

用于：

- 保存微信读书 API Key；
- 配置 Android 微信读书网络代理；
- 查看凭据状态和同步状态。

微信读书代理只影响微信读书同步，不影响 AI Provider 或应用更新。

### 10.2 AI 设置

用于：

- 选择 Provider 预设；
- 填写或刷新模型；
- 保存 AI API Key；
- 测试连通性和结构化输出兼容性；
- 配置阅读助手上下文偏好。

模型列表刷新失败时可以手动填写模型名称。

### 10.3 语义索引

用于：

- 保存独立的 Embedding Base URL、模型和 API Key；
- 测试 Embedding Provider 是否能返回向量及其维度；
- 明确授权后构建、继续、取消或清除本机语义索引；
- 查看索引进度、模型和错误信息。

向量模型不等于聊天模型：同一服务商的 Base URL 或 API Key 可能可以手动复用，但必须填写支持 `/embeddings` 的模型名称。更换向量模型、Base URL 或模型维度后，应清除并重建索引，不能混用旧向量。

“移除 Embedding Key”不会自动删除现有本地向量；“清除语义索引”只删除索引和任务记录，不会删除原始笔记、聊天 AI 设置或导出文件。

### 10.4 导出设置

用于：

- 设置 Markdown、复盘和诊断信息导出目录；
- 配置 Obsidian Vault 和附件策略；
- 配置 Notion Integration、数据库和字段映射；
- 创建或切换标准阅读成果库。

修改导出设置只影响之后的新导出，不会移动历史文件，也不会迁移已有 Notion 页面。

### 10.5 应用更新

Windows 可以在 `设置 > 应用更新` 检查 Release 更新，先查看版本摘要，再确认安装。

Android 不使用桌面 Tauri updater，需要从 GitHub Release 下载签名 APK，并按系统安装流程升级。

### 10.6 高级维护

用于：

- 导出本地备份；
- 恢复本地备份；
- 导出诊断信息；
- 查看数据库路径；
- 迁移本地数据目录；
- 清理 AI 成果缓存或助手历史。

清理 AI 成果缓存不会删除微信读书缓存、本地阅读状态或已经导出的文件。清理助手历史不会删除书籍复盘、阅读指南、阅读报告或选书决策。

## 11. 备份、恢复与数据目录迁移

### 11.1 SQLite 备份包含什么

本地备份包含：

- SQLite 主数据库；
- 存在时的 WAL 文件；
- 存在时的 SHM 文件。

不包含：

- 微信读书 API Key；
- AI API Key；
- Embedding API Key；
- Notion 凭据；
- 语义向量索引和索引任务记录；
- 其他系统安全存储文件；
- 本地阅读器的划线、想法和 AI 提问；
- 阅读器偏好和人工版本关联。

本地阅读器内容请另外导出 Markdown 或保留原始数据目录，不要只依赖 SQLite 备份。

### 11.2 正确的备份顺序

1. 打开 `设置 > 高级维护`。
2. 点击 `导出本地备份`。
3. 将备份包放到专用备份目录或外部磁盘。
4. 不要把备份包放在临时下载目录或会被自动清理的位置。

### 11.3 正确的恢复顺序

1. 打开 `设置 > 高级维护`。
2. 选择本地备份包并确认恢复。
3. 等待恢复完成，不要强制退出应用。
4. 完全退出并重新启动应用。
5. 先检查书架、笔记、阅读状态和成果，再继续同步或导出。
6. 保留原备份包，直到确认恢复结果正常。

如果应用版本差异较大，先升级到兼容版本再恢复。不要手工删除新数据库列、迁移备份表或直接覆盖真实用户数据库进行回退。

### 11.4 数据目录迁移

当系统盘空间不足，或需要把本地数据库放到其他磁盘时：

1. 进入 `设置 > 高级维护`。
2. 选择目标数据目录。
3. 确认迁移。
4. 等待迁移完成后重启应用。

迁移期间不要强制退出，也不要选择临时下载目录。API Key 仍由本机安全存储管理。

## 12. Android 使用差异

- 使用顶部栏和侧边抽屉导航，不显示桌面窗口控制。
- 低频入口集中在 `我的` 页面。
- 查找设置时优先进入 `我的 > 设置`。
- 微信读书同步失败时，检查 `我的 > 微信读书代理设置` 或 `设置 > 账户与同步`。
- 报告图片可以保存到系统相册或通过系统分享。
- 应用更新从 GitHub Release 下载 APK，不使用桌面端 updater。
- AI、导出、本地阅读器写入等能力以当前 Android 应用实际显示的入口、配置状态和错误提示为准，不把桌面端能力默认等同于移动端能力。

## 13. 常见问题

### 同步失败或提示需要升级

1. 检查 `设置 > 账户与同步` 中的凭据状态。
2. Android 检查代理工具是否运行，以及代理地址和端口是否正确。
3. 保存代理后重新执行对应页面的同步。
4. 如果提示需要升级微信读书 Skill 或接口版本，按提示处理后重试。
5. 反复失败时先使用本地已有缓存或已经导出的文件。

### AI 无法生成或模型列表为空

1. 检查 Provider、模型和 API Key 是否保存。
2. 先测试连通性和结构化输出兼容性。
3. 模型刷新失败时手动填写模型名。
4. 如果只有某本书失败，确认该书已经有可用的本地笔记缓存。
5. 不要把 API Key 粘贴到笔记、诊断信息或导出文档中。

### 导出失败、找不到文件或内容为空

1. 检查 `设置 > 导出设置` 中的目录是否存在且可写。
2. 修改目录后保存；新目录不会移动历史导出物。
3. 批量导出前先完成预检。
4. 排除没有划线、想法或对应成果缓存的书。
5. 关闭占用目标文件的其他程序后重试。
6. 查看结果页的目标级错误，不要只看总体状态。

### Notion 标签写入失败

确认：

- Integration 已共享给目标数据库；
- `标签` 仍映射到 Multi-select 属性；
- 数据库字段映射没有失效；
- Notion 允许当前 Integration 创建或编辑页面。

在结果页查看具体失败目标，必要时在 Notion 中补充选项后使用 `重试失败项`。

### 本地书和微信读书版本看起来混在一起

这是预期的数据边界。两个版本可以被人工关联，但分别保存进度、划线、想法和 AI 缓存，不会自动合并。

### Web Preview 里不能生成或导出

这是预期行为。Web Preview 是只读入口，只能查看已经准备好的数据和成果。请回到具备对应本地能力的桌面或移动应用，并确认凭据、AI Provider 和导出设置有效。

### 设置保存超时或页面没有更新

等待当前操作结束后重新打开设置页。Android 上可以完全退出应用后重启。如果问题仍然存在：

1. 导出诊断信息；
2. 记录版本、平台和复现步骤；
3. 联系维护者时不要附带 API Key。

## 14. 数据安全与使用边界

- API Key 和 AI API Key 按应用设计保存在本机，不写入 Markdown、Obsidian、Notion 导出和诊断信息。
- 删除微信读书凭据不会删除已经同步到本机的书架、笔记和统计缓存。
- 导出和备份前确认目标目录权限，不要把个人阅读记录放到公开共享目录。
- 本工具用于整理和导出自己合法获取的阅读数据，不用于获取他人数据、绕过付费内容或批量盗号。
- 如果平台规则或接口发生变化，优先保留本地缓存和已导出文件，并通过设置页的错误提示和诊断信息排查问题。
